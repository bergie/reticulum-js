# @reticulum/lxmf

LXMF (Lightweight Extensible Message Format) messaging for
[reticulum-js](https://reticulum.js.org/) — asynchronous, store-and-forward
messaging over the Reticulum Network Stack: one-to-one messages, the router,
paper/QR messaging, and propagation nodes. Wire-compatible with the Python
[LXMF](https://github.com/markqvist/LXMF) reference.

```js
import { LXMessage, LXMRouter } from "@reticulum/lxmf";
```

Requires `@reticulum/core` as a peer of your RNS stack setup. See the
[reticulum-js documentation](https://reticulum.js.org/) for guides and API
references.
